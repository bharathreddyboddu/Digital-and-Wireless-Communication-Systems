
# Digital and Wireless Communication Systems

## Project Overview

This project explores digital communication techniques through MATLAB/Simulink simulations and wireless voice communication using GNU Radio.

The project is divided into two major components.

## 1. Hardware Implementation – GNU Radio

This section demonstrates a wireless voice communication system using GNU Radio.

**Files included:**
- `Voice_transmitter.grc` – Transmitter flowgraph.
- `Voice_receiver.grc` – Receiver flowgraph.
- Hardware setup photograph.

## 2. Software Implementation – MATLAB/Simulink

This section focuses on digital modulation techniques and their performance over an Additive White Gaussian Noise (AWGN) channel.

**Techniques implemented:**
- Binary Phase Shift Keying (BPSK)
- Quadrature Phase Shift Keying (QPSK)

**Files included:**
- MATLAB scripts for BPSK and QPSK BER analysis.
- Simulink models for BPSK and QPSK over an AWGN channel.
- BER data files.
- Simulation graphs and results.

## 3. Results

The simulation results include:
- BPSK and QPSK system representations.
- Individual SNR versus BER plots.
- Comparative SNR versus BER analysis.

## 4. Project Documentation

Refer to the `Documentation` folder for the project report.
